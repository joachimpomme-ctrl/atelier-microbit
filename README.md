# Les ateliers micro:bit

Des missions pour apprendre à programmer une carte micro:bit V2 avec les blocs de MakeCode.
Le site est publié avec GitHub Pages.

## Ateliers

| Dossier | Atelier | État |
|---|---|---|
| `robot/` | L'atelier robot : robot MiniCar, 9 missions | prêt |
| `ia/` | L'atelier IA : micro:bit CreateAI | en préparation |

## Structure

- `index.html` : page d'accueil, liste des ateliers et progression.
- `robot/index.html` : l'atelier robot, page autonome (styles et script inclus).

Chaque atelier vit dans son propre dossier, avec son `index.html`.
Pour en ajouter un : créer le dossier, puis ajouter sa carte dans `index.html`.

## Données

Aucune donnée personnelle dans ce dépôt.
La progression, le carnet de bord et les prénoms de l'équipe sont enregistrés uniquement dans le navigateur (localStorage).

## Règles pédagogiques communes

- Une mission = un objectif concret, testable, en une phrase.
- Deux ou trois notions par mission, pas plus.
- Indices du plus léger au plus précis. La solution en dernier recours.
- On teste, on observe, on corrige une seule chose à la fois.
- Montages à piles ou en USB uniquement. Jamais rien relié au secteur.
