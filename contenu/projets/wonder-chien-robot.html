Premier projet Wonder ? Commence par Bien démarrer avec le kit Wonder, puis l'hélicoptère.

Construire : la fiche de montage (modèle 32).

moteur → M1

Prédis d'abord

Comment un seul moteur peut-il faire marcher quatre pattes ?

Le plan

  1. Construis le chien avec la fiche de montage, moteur sur M1.
  2. Bouton A : le moteur tourne et le chien marche.
  3. Bouton B : le moteur s'arrête.
  4. Teste-le sur une table dégagée, loin du bord.
Indice 1 · une question

Un seul moteur fait marcher les quatre pattes. Sur quelle prise est-il branché ?

Indice 2 · où chercher

Tiroir wuKong : Set motor M1 speed to … dans le bouton A, Stop motor M1 dans le bouton B.

Indice 3 · un exemple sur un autre cas

Dans l'hélicoptère, un bouton lançait l'hélice et un autre l'arrêtait. Ici, c'est un chien au lieu d'une hélice.

La mission : bouton A, le moteur M1 à une vitesse ; bouton B, arrêter le moteur M1.

Pour le défi : dans le bouton A, moteur M1 à 100, pause 3000 ms, arrêter le moteur M1, puis un son ou une icône.

Le programme du fabricant ELECFREAKS : programme officiel. Il fait la mission de base, sans le défi.

Défi bonusLe chien obéissant

Bouton A : il marche 3 secondes, s'arrête tout seul, puis aboie (son sur la micro:bit V2) ou remue la queue (une icône).

Un coup de pouce pour le défi

Qu'est-ce qui doit se passer, dans l'ordre, après un appui sur A ?

Un dresseur dit « marche », compte, puis « stop » : les ordres arrivent les uns après les autres.
