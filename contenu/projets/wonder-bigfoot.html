Construire : la fiche de montage (modèle 6).

moteur → M1

Prédis d'abord

Avec ses grosses roues, le monstre ira-t-il plus vite ou moins vite qu'une voiture à petites roues, pour la même vitesse de moteur ?

Le plan

  1. Construis le monstre avec la fiche de montage, moteur sur M1.
  2. Bouton A : le moteur tourne et le monstre avance.
  3. A et B ensemble : le moteur s'arrête.
  4. Teste-le d'abord posé sur un bol, roues dans le vide. Puis au sol, sur un espace dégagé.
Indice 1 · une question

Avec une vitesse de 100, le monstre avance ou recule ? Prédis, puis teste-le posé sur un bol, roues dans le vide.

Indice 2 · où chercher

Tiroir wuKong : Set motor M1 speed to … dans le bouton A. Pour l'arrêt, choisis A+B dans le petit menu du bloc lorsque le bouton … est pressé.

Indice 3 · un exemple sur un autre cas

Dans la moto, le signe de la vitesse décidait du sens : un nombre positif dans un sens, négatif dans l'autre.

La mission : bouton A, le moteur M1 à une vitesse qui fait avancer (son signe dépend du montage) ; boutons A+B, arrêter le moteur M1.

Pour le défi : « montrer l'icône » fâché dans le bouton A, endormi dans le bouton A+B.

Le programme du fabricant ELECFREAKS : programme officiel. Il fait la mission de base, sans le défi.
