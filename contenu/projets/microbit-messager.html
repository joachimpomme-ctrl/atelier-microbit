Ta mission : sur une carte, le bouton A envoie un cœur et le bouton B un sourire. L'autre carte affiche ce qu'elle reçoit. Et ça marche dans les deux sens.

Il faut deux cartes micro:bit, chacune avec son boîtier de piles.

Prédis d'abord

Faut-il écrire deux programmes différents, un pour chaque carte, ou un seul ?

Le plan

  1. Au démarrage : choisir un groupe radio, le même sur les deux cartes.
  2. Bouton A : envoyer le nombre 1. Bouton B : envoyer le nombre 2.
  3. Quand un nombre arrive : si c'est 1, un cœur ; si c'est 2, un sourire.
  4. Envoie le même programme sur les deux cartes.

Note dans le carnet

Indice 1 · une question

On envoie un nombre, pas une image. Comment l'autre carte sait-elle quelle image afficher ?

Indice 2 · où chercher

Le tiroir Radio : choisir le groupe, envoyer un nombre, réagir quand un nombre arrive.

Indice 3 · un exemple sur un autre cas

Un code secret entre deux amis : « 1 » veut dire « viens jouer », « 2 » veut dire « à table ». Quand ton ami reçoit « 2 », il sait tout de suite qu'il faut venir manger.
