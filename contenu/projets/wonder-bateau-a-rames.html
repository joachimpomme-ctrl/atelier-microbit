Construire : la fiche de montage (modèle 10).

moteur → M1

Prédis d'abord

Quand le bateau avance, les rames poussent l'eau vers l'avant ou vers l'arrière ?

Le plan

  1. Construis le bateau avec la fiche de montage, moteur sur M1.
  2. Bouton A : avancer. Bouton B : reculer.
  3. A et B ensemble : arrêter le moteur.
  4. Teste le d'abord posé sur un bol, roues ou pattes dans le vide. Puis au sol, sur un espace dégagé.
Indice 1 · une question

Avancer et reculer : qu'est-ce qui change entre les deux ordres, à part le bouton ?

Indice 2 · où chercher

Le même bloc Set motor M1 speed to … dans A et dans B, avec le même nombre mais pas le même signe. L'arrêt va dans A+B, à choisir dans le petit menu du bloc bouton.

Indice 3 · un exemple sur un autre cas

Un tapis roulant de supermarché : le même moteur fait avancer ou reculer le tapis, selon le sens où il tourne.

La mission : bouton A, le moteur M1 à une vitesse qui fait avancer ; bouton B, la même vitesse avec le signe opposé ; boutons A+B, arrêter le moteur M1.

Pour le défi : un bloc qui affiche une flèche ou une icône dans chacun des trois boutons, à côté du bloc du moteur.

Le programme du fabricant ELECFREAKS : programme officiel. Il fait la mission de base, sans le défi.
