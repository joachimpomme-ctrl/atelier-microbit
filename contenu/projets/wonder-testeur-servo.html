Ta mission : fabriquer un programme outil. Le bouton A tourne le servo de 10 degrés, le bouton B le ramène de 10 degrés, et l'écran affiche l'angle.

Pourquoi ? Le fabricant demande de régler le servo avant de le monter dans les briques. Sinon, il peut forcer contre une pièce et casser. Ce programme te servira pour la porte automatique, le chariot élévateur et toutes les machines avec un servo.

servo → S0

Le servo est branché seul, sans briques autour.

Prédis d'abord

Le servo démarre à 90°. Après 3 appuis sur A, à quel angle sera-t-il ?

Le programme outil

C'est le programme de réglage proposé par le fabricant. Construis-le bloc par bloc.

Pas à pas

  1. Crée une variable angle. Au démarrage : définir angle à 90, puis envoie le servo à cet angle.
  2. Dans toujours : montrer nombre angle.
  3. Bouton A : ajouter 10 à angle, puis renvoyer le servo à l'angle.
  4. Bouton B : pareil avec -10.
  5. Teste. Laisse le servo à 90 avant de le monter dans une machine.
Indice 1 · une question

Le nombre change mais le servo ne bouge pas ? Après avoir changé la variable, qui dit au servo d'aller au nouvel angle ?

Indice 2 · où chercher

Le bloc modifier angle de est dans le tiroir Variables. Le bloc Set 360° servo S0 angle to est dans le tiroir wuKong : glisse la variable angle dans son trou.

Indice 3 · un exemple sur un autre cas

Dans l'essuie-glace, les boutons changeaient seulement le nombre rangé dans la variable vitesse. C'est un autre bloc qui donnait ce nombre au moteur. Ici aussi, changer le nombre ne fait pas bouger le servo tout seul.
