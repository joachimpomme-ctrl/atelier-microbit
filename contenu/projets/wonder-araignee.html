Prédis d'abord

Quand l'araignée recule, ses pattes font-elles le même mouvement à l'envers, ou un autre mouvement ?

Indice 1 · une question

Combien de moteurs font bouger les huit pattes ? Regarde les branchements.

Indice 2 · où chercher

Un seul moteur, sur M1 : Set motor M1 speed to … dans A et dans B avec des signes opposés, Stop motor M1 dans A+B.

Indice 3 · un exemple sur un autre cas

Les rames d'une galère bougent toutes ensemble parce qu'elles suivent le même rythme. Ici, ce sont les engrenages qui relient les pattes.

La mission : bouton A, le moteur M1 à une vitesse qui fait avancer ; bouton B, la même vitesse avec le signe opposé ; boutons A+B, arrêter le moteur M1.

Pour le défi : le bloc qui réagit à une secousse, avec répéter 3 fois : moteur M1 à 100, pause 1000, moteur M1 à -100, pause 1000. Puis arrêter le moteur.

Le programme du fabricant ELECFREAKS : programme officiel. Il fait la mission de base, sans le défi.
