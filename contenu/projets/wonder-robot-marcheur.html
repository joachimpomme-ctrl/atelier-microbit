Construire : la fiche de montage (modèle 15).

moteur → M1

Prédis d'abord

Un seul moteur fait bouger plusieurs pattes. Comment est-ce possible ?

Le plan

  1. Construis le robot avec la fiche de montage, moteur sur M1.
  2. Bouton A : avancer. Bouton B : reculer.
  3. A et B ensemble : arrêter le moteur.
  4. Teste le d'abord posé sur un bol, roues ou pattes dans le vide. Puis au sol, sur un espace dégagé.
Indice 1 · une question

Le robot marche dans le mauvais sens ? Qu'est-ce qui, dans ton bloc, décide du sens ?

Indice 2 · où chercher

Dans Set motor M1 speed to …, le signe du nombre décide du sens. Un bloc par bouton : A, B, et A+B pour l'arrêt.

Indice 3 · un exemple sur un autre cas

Un rameur tire les rames vers lui pour avancer, et les pousse pour reculer. Le même geste, dans l'autre sens.

La mission : bouton A, le moteur M1 à une vitesse qui fait avancer ; bouton B, la même vitesse avec le signe opposé ; boutons A+B, arrêter le moteur M1.

La vitesse minimale dépend des frottements, du sol et de la batterie. Il n'y a pas de bonne réponse unique : c'est une mesure.

Le programme du fabricant ELECFREAKS : programme officiel. Il fait la mission de base, sans le défi.
