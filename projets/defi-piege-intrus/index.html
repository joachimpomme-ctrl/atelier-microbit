Ce projet a besoin d'une carte micro:bit V2 (logo doré sur la face avant).

Ta mission : une tour surveille la porte de ta chambre avec son capteur à ultrasons. Si quelqu'un passe, elle lève un drapeau, elle sonne et elle envoie une alerte par radio à ta carte de poche. Pour la désarmer, il faut un code secret sur son logo.

Matériel : le kit Wonder (carte Wukong avec sa batterie, sonar:bit, un servo) avec une carte micro:bit V2, pour le logo tactile. Une 2e carte, la carte de poche, avec son boîtier de piles. En option, le MiniCar comme chien de garde (3e carte).

carte 1 : tourcarte 2 : carte de poche
sonar:bit → P1servo → S0

Construis la tour à ton idée avec les briques. Le capteur vise l'autre montant de la porte. Règle le servo avec le testeur de servo avant de monter le drapeau. Pour ajouter les blocs du sonar, vois Bien démarrer avec le kit Wonder.

Choisis un numéro de groupe radio et écris-le sur un post-it collé sur chaque carte.

Sécurité : garde un volume raisonnable. Les câbles passent le long du mur, jamais en travers du passage.

Prédis d'abord

Tu passes devant la tour avec un gros pull tout doux, ou en tenant un coussin devant toi. À ton avis, le capteur te verra-t-il aussi bien qu'une boîte en carton ?

Le plan

  1. Pose la tour d'un côté de la porte, le capteur vers l'autre montant. Montre la distance sur l'écran. Note-la quand la porte est vide, puis quand quelqu'un passe.
  2. L'alarme : quand la distance devient nettement plus petite que celle de la porte vide, la tour sonne. Teste avec une boîte en carton, puis avec un coussin ou un gros pull. Compare avec ta prédiction.
  3. Le drapeau : quand l'alarme se déclenche, le servo le lève. Teste : il se lève sans forcer contre une brique.
  4. L'alerte radio : la tour envoie « intrus » (un nombre suffit). La carte de poche sonne et montre une icône. Teste depuis une autre pièce.
  5. Le code secret : une variable retient si la tour est armée. Un code sur le logo, par exemple un nombre précis d'appuis, la désarme et baisse le drapeau. Teste : un mauvais code ne la désarme pas.

Note dans le carnet

Noté.

Indice 1 · une question

Quand quelqu'un passe entre la tour et le montant, la distance mesurée devient-elle plus grande ou plus petite ?

Indice 2 · où chercher

Le tiroir de l'extension sonar:bit : Ultrasonic distance in unit cm at pin …, réglé sur P1. Le tiroir wuKong : Set 360° servo S0 angle to …. Le tiroir Radio pour l'alerte, le tiroir Variables pour « armé », le tiroir Entrées pour le logo.

Indice 3 · un exemple sur un autre cas

La sonnette d'une boutique fait « ding » quand un client entre. Elle ne sait pas qui entre. Elle remarque seulement que, devant la porte, quelque chose a changé par rapport à d'habitude.

La logique, en mots : sur la tour, au démarrage, choisir le groupe radio, baisser le drapeau avec le servo, mettre « armé » à vrai. Dans « toujours » : lire la distance. Si la tour est armée et que la distance est plus petite que le seuil (un peu moins que la porte vide), alors : un son, le drapeau levé, un nombre envoyé par radio. Sur la carte de poche : quand un nombre arrive, un son et une icône. Pour le code : chaque appui sur le logo ajoute 1 à un compteur. Quand le compteur atteint le nombre secret, « armé » passe à faux et le drapeau redescend.

Le sonar rate parfois les vêtements doux ou les objets placés en biais.

Pour aller plus loin : le projet officiel Tilt alarm, la même idée d'alerte par radio.

Défi bonusLe chien de garde

Ajoute le MiniCar (3e carte, même groupe radio). Quand il reçoit l'alerte, ses phares passent au rouge et il avance d'environ 30 cm. Ses blocs sont dans le tiroir de l'extension MiniCar : dans MakeCode, Extensions, colle l'adresse https://github.com/keyestudio2019/MiniCar. Pour régler les 30 cm, la vraie vitesse du robot peut t'aider.
