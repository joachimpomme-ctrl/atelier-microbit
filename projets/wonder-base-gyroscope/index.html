Ta mission : bouton B, le moteur démarre et lance le gyroscope posé sur les connecteurs jaunes. Quand il tourne assez vite, lâche-le : il ne tombe pas. Bouton A, le moteur s'arrête.

Premier projet Wonder ? Commence par Bien démarrer avec le kit Wonder, puis l'hélicoptère.

Construire : la fiche de montage (modèle 3).

moteur → M1

Prédis d'abord

Pourquoi un gyroscope qui tourne vite ne tombe-t-il pas, alors qu'il tombe quand il est immobile ?

Le plan

  1. Construis la base avec la fiche de montage, moteur sur M1.
  2. Bouton B : le moteur démarre.
  3. Bouton A : le moteur s'arrête.
  4. Teste d'abord sans le gyroscope. Puis pose-le sur les connecteurs jaunes et lance-le.
Indice 1 · une question

Deux boutons, deux ordres. Lequel lance le moteur, et lequel l'arrête ?

Indice 2 · où chercher

Tiroir Entrées : un bloc lorsque le bouton … est pressé pour chaque bouton. Tiroir wuKong : Set motor M1 speed to … pour lancer, Stop motor M1 pour arrêter.

Indice 3 · un exemple sur un autre cas

Un mixeur de cuisine a un bouton pour lancer et un autre pour arrêter. Chaque bouton a un seul travail, comme dans l'hélicoptère.

La mission : bouton B, le moteur M1 à la vitesse 100 ; bouton A, arrêter le moteur M1.

Pour le défi : dans le bouton B, trois fois « montrer nombre » suivi d'une pause de 1000 ms, puis le bloc du moteur M1 à vitesse 100.

Le programme du fabricant ELECFREAKS : programme officiel. Il fait la mission de base, sans le défi.
