Le messager Morse

Ce projet a besoin d'une carte micro:bit V2 (logo doré sur la face avant).

Ta mission : tu tapes une lettre en Morse sur ta carte : le bouton A fait un point, le bouton B un trait. Le MiniCar bipe et clignote ses phares en Morse, trouve la lettre et obéit : avec la lettre A, il avance ; avec G, il tourne à gauche ; avec S, il s'arrête.

Matériel : le robot MiniCar avec sa carte micro:bit V2 et ses 3 piles AAA, et une deuxième carte micro:bit pour taper le Morse, avec son boîtier de piles.

carte 1 : pilotecarte 2 : robot

Les trois lettres : A = point, trait (.-). G = trait, trait, point (--.). S = point, point, point (...).

Pour le programme du robot, ajoute l'extension MiniCar : dans MakeCode, clique sur Extensions, puis colle l'adresse https://github.com/keyestudio2019/MiniCar. Le robot bipe avec le haut-parleur de sa carte V2 : il ne semble pas avoir de buzzer à lui.

Choisis un numéro de groupe radio et écris-le sur un post-it collé sur chaque carte.

Sécurité : fais rouler le robot au sol, loin des escaliers. Prévois un arrêt d'urgence sur le robot : A et B ensemble, les moteurs s'arrêtent.

Prédis d'abord

Tu tapes la lettre A, puis tout de suite la lettre S, sans faire de pause entre les deux. Que va faire le robot ?

Le plan

  1. Sur la carte du pilote, le bouton A envoie le texte « . » par radio, le bouton B envoie « - ». Le robot affiche ce qu'il reçoit. Teste : A, puis B.
  2. Le robot bipe et allume ses phares : court pour un point, long pour un trait. Teste : ferme les yeux pendant que ton copain tape. Reconnais-tu le point et le trait à l'oreille ?
  3. Le robot colle les symboles reçus les uns derrière les autres. Quand plus rien n'arrive pendant 1 s, la lettre est finie : il affiche le code complet, puis l'efface et recommence. Teste avec la lettre A.
  4. Décode avec deux listes rangées dans le même ordre : une pour les codes, une pour les lettres. Teste : tape S, le robot affiche S.
  5. Fais obéir le robot : A, il avance ; G, il tourne à gauche ; S, il s'arrête. Teste : envoie 3 lettres, le robot fait 3 mouvements. Puis vérifie ta prédiction.

Note dans le carnet

Noté.

Indice 1 · une question

Quand tu tapes un point, le robot ne sait pas encore quelle lettre tu veux. À quel moment peut-il en être sûr ?

Indice 2 · où chercher

Le tiroir Radio : envoyer un texte, réagir quand un texte arrive. Sous « Avancé », cherche le tiroir du texte, pour coller deux textes, et celui des listes, que MakeCode appelle des tableaux, pour chercher dans une liste. Le tiroir Entrées : un bloc rond donne le temps écoulé depuis le démarrage, en millisecondes. Le tiroir Musique pour les bips.

Indice 3 · un exemple sur un autre cas

Deux listes de ta classe, rangées dans le même ordre : sur la première, les prénoms ; sur la seconde, les dates d'anniversaire. Léa est la cinquième de la première liste ? Sa date est la cinquième de la seconde.

La logique, en mots : le pilote choisit le groupe radio au démarrage. Bouton A : envoyer le texte « . ». Bouton B : envoyer « - ». Le robot, au démarrage : deux listes dans le même ordre, les codes (« .- », « --. », « ... ») et les lettres (« A », « G », « S »), et une variable code, vide. Quand un texte arrive : bip et phares, courts pour « . », longs pour « - » ; coller le symbole au bout de code ; retenir dans une variable le moment de ce symbole (le temps écoulé). Toujours : si code n'est pas vide et que plus de 1000 ms ont passé depuis le dernier symbole, chercher la position de code dans la liste des codes, prendre la lettre à la même position, l'afficher et faire le mouvement. Puis vider code. Une fonction qui bipe et allume les phares pour un symbole rend le programme plus clair.

Si le code n'est dans aucune liste, par exemple deux lettres tapées sans pause, la recherche ne trouve pas de position (elle donne -1) : le robot peut montrer une croix et vider le code.

Pour aller plus loin : l'activité radio du cours MakeCode, avec Marco Polo et le Morse (en anglais).

Défi bonusLe Morse lumineux

Une autre carte regarde les phares du robot avec son capteur de lumière (l'écran de la carte sert de capteur) et essaie de lire le Morse toute seule. Personne n'a encore vérifié que ça marche : c'est une vraie expérience. Note ce que tu observes.
