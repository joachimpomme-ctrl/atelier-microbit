Ce projet a besoin d'une carte micro:bit V2 (logo doré sur la face avant).

Ta mission : bouton A, une mélodie. Bouton B, une autre mélodie. Le logo doré, un son rigolo.

Prédis d'abord

Tu appuies sur A, puis tout de suite sur B, avant la fin de la première mélodie. Qu'est-ce que tu vas entendre ?

Les blocs à utiliser

Pas à pas

  1. lorsque le bouton A est pressé, avec dedans le bloc du tiroir Musique qui joue une mélodie. Choisis-en une.
  2. Pareil pour le bouton B, avec une autre mélodie.
  3. Tiroir Entrées : le bloc qui réagit quand on touche le logo, avec un son du tiroir Musique.
  4. Le simulateur joue aussi les sons : teste avant d'envoyer.
Indice 1 · une question

Ta carte doit réagir à combien de choses différentes ? Pour chacune, il te faut un grand bloc avec le son dedans.

Indice 2 · où chercher

Les mélodies et les sons sont dans le tiroir Musique. Le bloc du logo est dans le tiroir Entrées, avec les boutons. Il marche seulement sur une micro:bit V2. Dans le simulateur, clique sur le logo pour le toucher.

Indice 3 · un exemple sur un autre cas

Sur un piano, chaque touche a sa propre note. Quand tu appuies sur une touche, tu entends la note de cette touche. Ta carte, c'est un piano à trois touches : A, B et le logo.
