Ce projet a besoin d'une carte micro:bit V2 (logo doré sur la face avant).

Ta mission : tu tapes une fois dans tes mains, le MiniCar démarre. Deux claps rapides, il fait demi-tour. Trois claps, il danse avec ses phares.

Premier projet avec le MiniCar ? Commence par le parcours robot.

Matériel : le robot MiniCar avec sa carte micro:bit V2 et ses 3 piles AAA. Une seule carte suffit : le micro qui entend les claps est sur la carte V2.

Les blocs du robot sont dans le tiroir de l'extension MiniCar. Pour l'ajouter : dans MakeCode, clique sur Extensions, puis colle cette adresse dans la recherche.

https://github.com/keyestudio2019/MiniCar

Sécurité : prévois un arrêt d'urgence. Les boutons A et B appuyés ensemble arrêtent les moteurs.

Prédis d'abord

Quand le robot roule, ses moteurs font du bruit. À ton avis, peut-il « s'entendre » et croire que tu as tapé dans tes mains ?

Ton cahier des charges

À remplir avant de coder. À la fin, la page te le rappelle pour vérifier.

1. Ton critère de réussite. Comment sauras-tu que c'est réussi ? Écris-le avec un nombre : une distance, un temps, ou un nombre d'essais réussis.

Exemple sur un autre cas, le dé électronique. Mauvais critère : « il marche bien », on ne peut pas le vérifier. Bon critère : « je le secoue 10 fois, il affiche 10 fois un nombre de 1 à 6 ».

2. Ton compromis. Ton seuil de bruit doit-il être bas ou haut ?

Il n'y a pas de bonne réponse : ce qui compte, c'est ta raison. Tu pourras changer d'avis après les tests.

Le plan

  1. Montre le niveau sonore sur l'écran, sans arrêt. Note le nombre dans le silence, puis quand tu tapes dans tes mains.
  2. Choisis un seuil entre ces deux nombres. À chaque clap, les phares s'allument un instant. Teste : un clap allume les phares, ta voix normale non.
  3. Compte les claps : chaque clap ajoute 1 à un compteur, et les claps tapés en moins d'1 seconde comptent ensemble. Montre le compteur sur l'écran. Prédis : si tu tapes deux fois très lentement, combien la carte va-t-elle compter ?
  4. Une action pour chaque nombre : 1 clap, il démarre ; 2 claps, demi-tour ; 3 claps, la danse des phares. Ensuite, le compteur revient à 0. Teste chaque nombre, robot posé au sol.
  5. Lance le robot avec un clap, puis ne fais plus aucun bruit. Observe-le un moment. Compare avec ta prédiction.

Note dans le carnet

Le niveau sonore va de 0 à 255.

Noté.

Indice 1 · une question

Deux claps rapides, c'est un seul ordre. Deux claps tapés à 5 secondes d'écart, ce sont deux ordres. Comment la carte peut-elle faire la différence ?

Indice 2 · où chercher

Le tiroir Entrées : le niveau sonore, le bloc qui réagit à un son fort, et le bloc qui règle à partir de quel niveau un son compte comme fort. Toujours dans Entrées, un bloc donne le temps écoulé depuis l'allumage de la carte, en millisecondes. Le compteur se fabrique dans le tiroir Variables. Les moteurs et les phares sont dans le tiroir de l'extension MiniCar.

Indice 3 · un exemple sur un autre cas

La souris d'un ordinateur : un clic sélectionne, un double-clic ouvre. Après le premier clic, l'ordinateur attend un tout petit moment pour voir si un deuxième arrive. Ensuite seulement, il décide.

La logique, en mots : au démarrage, règle le seuil du son fort avec la valeur notée dans le carnet. Quand un son fort arrive : ajoute 1 au compteur et range le temps écoulé dans une variable « dernier clap ». Dans « toujours » : si le compteur est plus grand que 0 et que plus de 1000 ms sont passées depuis le dernier clap, alors regarde le compteur (1, 2 ou 3), fais l'action, puis remets le compteur à 0. Une autre variable peut retenir si le robot roule ou s'il est arrêté.

Si le robot réagit tout seul pendant qu'il roule, le bruit de ses moteurs en est peut-être la cause. Deux pistes à essayer : monter le seuil, ou n'écouter les claps que quand le robot est arrêté.
