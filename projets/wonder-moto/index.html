La moto

Ta mission : bouton A, la moto avance. Bouton B, elle recule. A et B ensemble, elle s'arrête.

Construire : la fiche de montage de la moto (modèle 1).

moteur → M1moteur → M2

Prédis d'abord

Les moteurs sont montés face à face, un de chaque côté. Pour que la moto avance, la vitesse doit-elle être positive ou négative ?

Les blocs à utiliser

Pas à pas

  1. Bouton A : set motor M1 speed … M2 speed … avec 100 et 100.
  2. Bouton B : le même bloc, avec -100 et -100.
  3. Bouton A+B (choisis A+B dans le petit menu) : Stop all motor.
  4. Test sur un bol d'abord. Avec 100, la moto avance ou recule ?
  5. Si elle recule, échange les valeurs entre A et B. Note le résultat ci-dessous.
Indice 1 · une question

Avancer et reculer, c'est le même mouvement dans deux sens opposés. Entre le bouton A et le bouton B, qu'est-ce qui doit changer dans les nombres du bloc ?

Indice 2 · où chercher

Le bloc qui règle les deux moteurs est dans le tiroir wuKong. Pour A et B ensemble : prends lorsque le bouton A est pressé dans le tiroir Entrées, puis choisis A+B dans son petit menu.

Indice 3 · un exemple sur un autre cas

Une voiture a une marche avant et une marche arrière. C'est le même moteur : seul le sens change. Dans le bloc, c'est le signe devant le nombre qui choisit le sens.

Note dans le carnet

Avec les deux vitesses à 100, la moto…

Le fabricant fait avancer ses véhicules avec des vitesses négatives.

Ta réponse règle aussi les solutions de la voiture prudente, du suiveur de ligne et du chariot.
