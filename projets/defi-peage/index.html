Ce projet a besoin d'une carte micro:bit V2 (logo doré sur la face avant).

Ta mission : le MiniCar suit une ligne noire jusqu'au péage. La barrière, construite avec le kit Wonder, le voit arriver et lui dit de s'arrêter. Elle lui demande son badge par radio. Si le code est bon, elle se lève et lui donne le feu vert.

Matériel : le robot MiniCar (carte micro:bit V2, 3 piles AAA). Pour la barrière, le kit Wonder : la carte Wukong avec sa batterie, une deuxième carte micro:bit, un servo et le sonar:bit. En option, une troisième carte micro:bit avec un boîtier de piles (2 piles AAA) ou une batterie USB, pour le panneau compteur. La piste : du ruban adhésif noir sur une grande feuille blanche, avec la barrière au bord.

carte 1 : barrièrecarte 2 : MiniCarservo → S0sonar:bit → P1

Règle le servo avec le testeur de servo avant de fixer le bras de la barrière. Pour la barrière seule, la porte automatique fait presque la même chose.

Les blocs du robot sont dans le tiroir de l'extension MiniCar. Pour l'ajouter : dans MakeCode, ouvre Extensions et colle l'adresse https://github.com/keyestudio2019/MiniCar.

Choisis un numéro de groupe radio et écris-le sur un post-it collé sur chaque carte. La barrière et le robot ont le même.

Sécurité : le bras de la barrière ne doit pas pincer les doigts. Fais-le bouger doucement, et garde les doigts hors de son chemin.

Prédis d'abord

Le robot suit la ligne dans une boucle toujours. Quand il reçoit « stop », tu arrêtes ses moteurs. À ton avis, va-t-il rester arrêté devant la barrière ?

Le plan

  1. La barrière seule : avec le testeur, trouve l'angle « baissée » et l'angle « levée ». Note-les. Puis : si le sonar:bit voit un objet à moins de 10 cm, la barrière se lève, attend, puis se baisse. Teste avec ta main.
  2. Le robot seul : il suit la ligne, comme dans le suiveur de ligne de l'atelier robot. Ajoute : quand il reçoit « stop », il s'arrête. Teste avec la carte de la barrière, qui envoie « stop » quand tu appuies sur A. Compare avec ta prédiction.
  3. La conversation : quand le sonar:bit voit le robot, la barrière envoie « stop », puis « badge ? ». Le robot répond avec son code. La barrière affiche le code reçu. Teste.
  4. La réponse : si le code est le bon, la barrière se lève et envoie « go », et le robot repart. Sinon, elle reste baissée. Elle se baisse quand le robot est passé. Teste aussi avec un mauvais code, puis deux passages de suite.

Note dans le carnet

Noté.

Indice 1 · une question

Le robot reçoit trois messages différents : « stop », « badge ? » et « go ». La barrière, elle, reçoit des codes. Comment chaque carte sait-elle ce qu'elle vient de recevoir, et quoi faire ?

Indice 2 · où chercher

Le tiroir Radio : un bloc envoie un texte, un autre réagit quand un texte arrive. Le tiroir Logique pour comparer ce qui est arrivé. Pour la barrière : Set 360° servo S0 angle to … (tiroir wuKong) et Ultrasonic distance in unit cm at pin … (tiroir sonar:bit). Pour le robot : les blocs du tiroir de l'extension MiniCar.

Indice 3 · un exemple sur un autre cas

Un gardien devant une cabane. « Halte ! » : tu t'arrêtes. « Mot de passe ? » : tu réponds. Si c'est le bon, il ouvre et dit « Entre ! ». Chacun attend la phrase de l'autre avant de parler.

La logique, en mots : pour s'y retrouver, chaque message commence par une lettre qui dit qui parle, « B » pour la barrière et « R » pour le robot. Par exemple « Bstop », « Bbadge », « Bgo » et « R42 ».

Barrière : une variable état (libre, attend, ouverte). Dans toujours, si l'état est libre et que la distance est plus petite que 10 : envoyer « Bstop », puis « Bbadge », état = attend. Quand un texte arrive : si c'est « R » suivi du bon code, lever le bras, envoyer « Bgo », état = ouverte. Si l'état est ouverte et que le sonar:bit ne voit plus rien de proche : baisser le bras, état = libre.

Robot : une variable roule, vraie au départ. Dans toujours, si roule est vrai, il suit la ligne ; sinon, moteurs arrêtés. Sans cette variable, la boucle relance les moteurs juste après le « stop ». Quand « Bstop » arrive : roule = faux. Quand « Bbadge » arrive : il envoie « R » et son code. Quand « Bgo » arrive : roule = vrai.

Les morceaux viennent de la porte automatique et du suiveur de ligne de l'atelier robot.
