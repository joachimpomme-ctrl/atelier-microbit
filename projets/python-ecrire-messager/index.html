Indice 1 · une question

Un bouton a son def et une ligne qui le relie au bouton. La réception d'un nombre par radio, c'est aussi un événement qui attend. S'écrit-elle de la même façon ?

Indice 2 · où chercher

L'astuce du dictionnaire : mets dans les Blocs le bloc du tiroir Radio qui réagit quand un nombre est reçu, regarde ce qu'il devient en Python, puis efface-le et réécris-le de mémoire. Dedans : un if et un elif, comme dans pierre-feuille-ciseaux.

Indice 3 · un exemple sur un autre cas

Le smiley de Bien démarrer en Python : un def, une ligne décalée par action, puis une ligne qui relie le def au bouton. Ton morceau suit le même modèle, avec une condition à l'intérieur.

Construis cette solution en blocs dans un autre projet, puis passe en Python et compare avec ce que tu as écrit. Le morceau de réception reçoit le nombre dans receivedNumber. Les erreurs les plus fréquentes : un décalage oublié, les deux-points oubliés, ou deux def qui portent le même nom.
