Juste le plan

Votre mission : découvrir comment les vitesses des deux moteurs changent le dessin. Vous devenez des scientifiques : une prédiction, un essai, un résultat.

Construire : la fiche de montage de la machine à dessiner (modèle 31). Le feutre se fixe avec l'élastique du kit.

moteur → M1moteur → M2

Un feutre lavable, et une grande feuille posée sur un carton.

Le plan

  1. Bouton A : les deux moteurs démarrent. Bouton B : tout s'arrête.
  2. Pour chaque essai du carnet : écrivez votre prédiction, puis lancez le dessin.
  3. Changez une seule vitesse à la fois.

Indice 1 · une question

Le dessin de l'essai 2 ressemble-t-il à celui de l'essai 1 ? Qu'est-ce qui a changé entre les deux, et seulement ça ?

Indice 2 · où chercher

Le bloc set motor M1 speed … M2 speed … règle les deux vitesses d'un coup. Il suffit de changer ses deux nombres entre deux essais.

Indice 3 · un exemple sur un autre cas

Pour savoir quel ingrédient rend un gâteau plus moelleux, un pâtissier ne change qu'un ingrédient à la fois. Sinon, il ne saurait pas lequel a compté.

Le programme est court : tout l'intérêt est dans l'expérience. Quand les deux vitesses sont proches, les boucles se ressemblent. Quand elles sont opposées, la machine tourne sur place. Laissez les enfants formuler leur propre règle.
